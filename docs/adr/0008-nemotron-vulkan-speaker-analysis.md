# Nemotron Vulkan speaker analysis on Windows GPU

Issue #17 extends ADRs 0005–0007. Windows x64 GPU builds use NVIDIA Nemotron 3 Diarization Q8 through the native NeMo-Speech.cpp 0.3.0 CLI. Windows x64 CPU and macOS arm64 retain Community-1. Whisper recognition and its save boundary stay unchanged; the existing SessionSpeakerWorkflow owns both automatic analysis after recognition and standalone retry.

The native adapter passes one selected mono 16 kHz PCM WAV to `diarize --device vulkan:0 --preset v3-offline --concurrency 1 --format json`. The preset preserves model state across the recording; independent chunk labeling would lose speaker identity. `--offline` is not used because the runtime's full-attention mode has a duration limit. The doctor command must identify a compatible Vulkan GPU and the pinned runtime before inference. Explicit Vulkan initialization failure is an error, with no CPU inference retry. Auxiliary work is bounded: one file worker, the upstream four-thread ggml default, OMP/BLAS limits of two, below-normal worker priority and two FFmpeg threads. Phase-only inference progress is intentional: the CLI does not publish a reliable percentage. Cancellation kills the child, awaits close, and removes temporary audio/output before releasing the operation.

The JSON protocol supplies arbitrary speaker labels and overlapping `{start,end,speaker}` segments, without confidence or word timestamps. Validate bounds against the prepared WAV duration and normalize labels into a run-local namespace. Preserve native overlap in `acousticIntervals`; do not claim Community-1 exclusive output. The existing conservative assignment policy requires a clear majority and leaves ambiguous, overlapped or uncovered fragments Unknown. Range and track offsets are applied once by the session workflow. Microphone-only sessions still bypass assets/inference and use a fixed microphone identity. Nemotron exposes automatic count only: UI hides exact count and main rejects an explicit count before downloading or replacing results.

Keep session/transcript version 1 and extend optional provenance version 1 as an engine-discriminated union. Native provenance records model and runtime revisions/hashes, Vulkan device, preset, audio mode, selected range, assignment policy and acoustic intervals. Older Community-1/sherpa sessions retain their labels and original text without migration or background reanalysis. Corrections, merges, source checks and recognition-generation guards remain in the shared workflow; save replaces the transcript atomically only when analysis is complete and still current.

Reuse the existing component downloader, hash checks, safe ZIP extraction, atomic installation/repair and offline cache. Native DLLs live beside the CLI in a private component root, with a restricted PATH; they never enter Whisper's directory. Pin inputs in `scripts/nemotron-assets.json`, include upstream Apache-2.0/third-party notices and the model's OpenMDW-1.1 license/card, and verify every packaged file. Upstream 0.3.0 uses narrow Windows path APIs: replace only its embedded asInvoker manifest to enable the UTF-8 active code page, record revision `nemo-speech-0.3.0+utf8.1`, and ship a modification notice. This requires Windows 10 1903 or later. The installer bundles metadata/notices; the approximately 124 MB component is downloaded on demand. Release acceptance also measures actual paired installers, not only model/archive sizes.
